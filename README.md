## 🎯 研究方向

| 方向 | 描述 | 状态 |
|:-----|:-----|:-----:|
| 🧬 基因分析 | DNA/RNA 序列分析与特征提取 | 🚧 |
| 🧪 蛋白质结构 | 蛋白质结构预测与功能分析 | 🚧 |
| 🦠 合成生物 | 基因回路设计与优化 | 📋 |
| 💊 药物发现 | AI 辅助药物分子设计 | 📋 |
| 📊 组学数据 | 转录组/蛋白质组数据分析 | 📋 |

## 🚀 快速开始

```bash
git clone https://github.com/ENDcodeworld/BioAI-Lab.git
cd BioAI-Lab
pip install -r requirements.txt
```
